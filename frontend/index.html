WFO & ML Ayarları

Otonom optimizasyon ve yapay zeka

Walk-Forward Optimization

💡 168 saat = 1 hafta (önerilen)

🤖 ML Model Ayarları

💡 ≥65% güven → İşlem açılır. Düşük threshold daha fazla sinyal, yüksek threshold daha kaliteli sinyal.

HTF (Multi-Timeframe) Analizi

Altın Oran: Major HTF veto yetkisine sahiptir. Örnek: 1m bot → 15m (Minor) + 1h (Major). Major trend ters yönde ise işlem açılmaz.

🔮 Kalman Filtresi (Denoising)

Fiyat gürültüsünü azalt, false sinyalleri filtrele

💡 Küçük değer (0.001) = Daha smooth, büyük değer (0.01) = daha hızlı tepki

💡 Büyük değer = Fiyat değişimlerine daha agresif tepki

🔮 Plug & Play: Bu ayarı değiştirdiğinizde tüm stratejiler otomatik olarak filtrelenmiş veriyle (smoothed_close) çalışır. Orijinal close fiyatı korunur.

⏱️ Katı Mum Kapanış Kilidi

Sinyalleri sadece mum kapanışında üret, ara dakikalarda atla

💡 Kaç saniyede bir mum kapanışını kontrol etsin? (Düşük = daha hızlı tepki)

ÖNEMLİ: Sinyal üretimi mum kapanışını bekler, ancak çıkış (exit) ve trailing stop ASLA beklemez - anlık çalışır!

🔐 API Yönetimi

Binance API anahtarlarını güvenli şekilde yönet

🔒 Fernet Şifreleme: API anahtarlarınız AES-128-CBC ile şifrelenerek .env dosyasında saklanır.

API İzinleri: Sadece Spot & Futures Trading izni verin. Withdrawal (Para Çekme) izni ASLA vermeyin!

🏗️ Parquet Data Lake Mimarisi Aktif

Sistem otomatik olarak SADECE 1 dakikalık mumları indirir ve Parquet formatında kaydeder.

Diğer zaman dilimleri (5m, 15m, 1h, 4h, vb.) otomatik olarak oluşturulur ve data/ohlcv/binance/ klasörüne kaydedilir.

✅ Avantajlar:

  • Apache Parquet (columnar storage - %70 daha az yer)
  • Snappy compression (hızlı okuma/yazma)
  • MTF-Daily (1m, 5m, 15m) → Gün bazlı partition (YYYY/MM/DD/)
  • MTF-Market (1h, 4h, 1d) → Tek dosya (market.parquet)
  • Look-ahead bias koruması (gelecek mumlar düşürülür)
  • OOM koruması (50k batch stream - RAM dostu)
